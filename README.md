# Rialo Testnet Explorer

A real-time block explorer for the Rialo Blockchain Testnet.

## ✨ Features
- **Real-Time Live Feed**: Instant block and transaction progression.
- **SubDAG Consensus Monitor**: Real-time validator node status and quorum tracking.
- **Rich Account Analytics**: Token balances, native Kelvin transfers, and paginated transaction histories.
- **Search Engine**: Search by Block Height, Transaction Signature, or Wallet/Contract Address.
- **Modern Glassmorphism UI**: Designed with high-performance Vanilla CSS and Vite.
